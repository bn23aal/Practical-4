# Practical 4: Preprocessing

6COM2005 Data Mining and Visualisation

## Aims
- Find data quality problems: missing values, duplicates, inconsistent text, wrong units, impossible values.
- Clean the data and document every change.
- Find outliers with the IQR and z-score rules.
- Encode categorical features and scale numeric features.
- Reduce data with stratified sampling and PCA.

## Files
- `Practical_4_T.ipynb`: the notebook you complete
- `6COM2005_DMV_Practical_4.docx`: the handout with all tasks
- `penguins_messy.csv`: a messy copy of Palmer Penguins with quality problems to fix
